# Reduce PDF Size 网站完成检查清单

本清单用于开发完成后的逐项验收。每一项都应记录证据；标记为 **阻断项** 的检查失败时不能上线。

## 使用方法

- 完成检查后将 `[ ]` 改为 `[x]`。
- 在条目末尾或验收记录中附上测试结果、截图、报告或 URL。
- `N/A` 必须写明不适用原因，不能直接跳过。
- 任何代码、内容或部署配置变更后，应重跑受影响的检查。

- [ ] **STR-003 阻断项** `.openai/hosting.json` 位于 `site/.openai/hosting.json`。
- [ ] **STR-004** 所有开发、测试、构建和部署说明均以 `site/` 为工作目录。
- [ ] **BLD-001 阻断项** 在干净环境安装依赖成功。
- [ ] **BLD-002 阻断项** 生产构建成功且没有被忽略的编译错误。
- [ ] **BLD-003** 类型检查和项目约定的静态检查通过。
- [ ] **BLD-004** 生产构建不包含调试页面、测试密钥、示例文件或开发占位文案。

## B. 核心压缩流程

- [ ] **FUN-001 阻断项** 点击选择有效 PDF 可以进入待处理状态。
- [ ] **FUN-002 阻断项** 拖放有效 PDF 可以进入待处理状态。
- [ ] **FUN-003** 拖放区支持键盘聚焦和键盘选择文件。
- [ ] **FUN-004 阻断项** 正确显示文件名和原始文件体积。
- [ ] **FUN-005 阻断项** High Quality、Balanced、Smallest Size 三档均可选择。
- [ ] **FUN-006** 首次选择文件时默认档位为 Balanced。
- [ ] **FUN-007 阻断项** 三个档位分别传递正确的压缩参数。
- [ ] **FUN-008 阻断项** 压缩在 Web Worker 中执行，处理期间主界面仍可响应。
- [ ] **FUN-009** 页面显示 Preparing、Compressing、Finalizing 等真实阶段，不伪造精确百分比。
- [ ] **FUN-010 阻断项** 成功后显示原始体积、输出体积、节省体积和压缩比例。
- [ ] **FUN-011 阻断项** 下载文件名符合 `{original-name}-reduced.pdf`。
- [ ] **FUN-012 阻断项** 下载后的 PDF 可以正常打开。
- [ ] **FUN-013** Reset/New File 可以清理当前结果并处理新文件。
- [ ] **FUN-014** 用户可以取消正在执行的任务。
- [ ] **FUN-015 阻断项** 取消后 Worker、内存文件、Blob 和对象 URL 得到清理。
- [ ] **FUN-016 阻断项** 连续处理多个文件不会复用上一次的文件内容或结果。
- [ ] **FUN-017 阻断项** 如果输出不小于输入，不显示压缩成功或负节省比例。
- [ ] **FUN-018** 输出不小于输入时，提示尝试更强档位或保留原文件。

## C. 文件验证和错误处理

- [ ] **VAL-001 阻断项** 非 PDF 文件被拒绝。
- [ ] **VAL-002 阻断项** 只改成 `.pdf` 扩展名但文件头不合法的文件被拒绝。
- [ ] **VAL-003** 空文件被拒绝。
- [ ] **VAL-004 阻断项** 超过 100MB 的文件在加载压缩引擎前被拒绝。
- [ ] **VAL-005 阻断项** 损坏 PDF 显示可理解的错误信息。
- [ ] **VAL-006 阻断项** 密码保护或加密 PDF 被拒绝并说明原因。
- [ ] **VAL-007 阻断项** 检测到数字签名的 PDF 被阻止重写，并提示签名风险。
- [ ] **VAL-008** WASM 加载失败时提供重试建议。
- [ ] **VAL-009** 浏览器内存不足或 Worker 异常时不会留下永久加载状态。
- [ ] **VAL-010** 所有错误提示都提供下一步，不只显示内部错误代码。
- [ ] **VAL-011** 用户文件名在页面中按纯文本显示，不会被解释为 HTML。

- [ ] **PDF-001 阻断项** 文字型 PDF 压缩后页数与原文件一致。
- [ ] **PDF-002 阻断项** 图片型 PDF 压缩后页数与原文件一致。
- [ ] **PDF-003 阻断项** 扫描型 PDF 压缩后页数与原文件一致。
- [ ] **PDF-004 阻断项** 横版、竖版和混合尺寸 PDF 的页面尺寸与方向正确。
- [ ] **PDF-005 阻断项** 固定测试样本的关键页面视觉对比在允许误差内。
- [ ] **PDF-006** 普通文字 PDF 压缩后文字仍可选择和复制。
- [ ] **PDF-007** High Quality 输出清晰度符合档位说明。
- [ ] **PDF-008** Balanced 输出在清晰度和体积之间符合默认定位。
- [ ] **PDF-009** Smallest Size 确实优先减小文件，并在页面说明质量风险。
- [ ] **PDF-010** 已高度优化的 PDF 触发“无法进一步减小”保护逻辑。
- [ ] **PDF-011** 测试带批注、表单、附件或图层的文件，并确认实际表现与条款说明一致。

## E. 隐私与安全

- [ ] **PRV-001 阻断项** 浏览器网络拦截证明 PDF 字节没有发送到服务器。
- [ ] **PRV-002 阻断项** PDF 内容没有进入 fetch、XHR、表单提交、日志、遥测或错误上报。
- [ ] **PRV-003 阻断项** WASM、Worker 和相关资源全部从本站同源加载。
- [ ] **PRV-004** 页面关闭、重置或任务结束后对象 URL 被撤销。
- [ ] **PRV-005** 不使用第三方文件上传服务。
- [ ] **PRV-006 阻断项** Firebase Analytics 不接收 PDF 字节或压缩结果，应用代码不向统计事件附加文件名或压缩档位，且隐私页准确披露统计范围。
- [ ] **SEC-001 阻断项** 生产环境没有公开密钥、令牌或部署凭证。
- [ ] **SEC-002 阻断项** CSP 只允许实际需要的同源资源与 Firebase Analytics 明确依赖的 Google 域名，没有宽泛第三方通配。
- [ ] **SEC-003** 依赖安全检查没有未评估的高危问题。
- [ ] **SEC-004 阻断项** 使用当前支持的 Ghostscript 源码构建，不发布未经评估的陈旧预编译二进制。
- [ ] **SEC-005** Ghostscript/WASM 构建版本、源码来源和校验信息可追溯。
- [ ] **SEC-006** 页面不能通过文件名、错误文本或查询参数注入脚本或 HTML。
